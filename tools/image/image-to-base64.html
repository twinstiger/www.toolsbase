❓ FAQ

What is a Base64 data URI?
A Base64 data URI encodes an image as a text string that can be used directly in an <img src=""> tag or CSS background-image property, eliminating the need for an external image file.
Is the image uploaded anywhere?
No — all conversion happens locally in your browser. Your image never leaves your device.
