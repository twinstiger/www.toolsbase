Generate RFC 4122 compliant UUID v4 — cryptographically random, browser-native.

📖 What is UUID v4?

A UUID (Universally Unique Identifier) v4 is a 128-bit number formatted as xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx. The y character is always 8, 9, A, or B, making it RFC 4122 compliant. UUIDs are generated using crypto.getRandomValues() — the same secure random source used by browsers for security-sensitive operations.
