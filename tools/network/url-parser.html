❓ FAQ

What URL parts are parsed?
All standard URL components: protocol/scheme, host, port, path, query string, and hash/fragment. Query parameters are also split into individual key-value pairs.
Does this work with any URL scheme?
Yes — it supports http, https, ftp, mailto, and other standard URL schemes. Click any component to copy it to clipboard.
