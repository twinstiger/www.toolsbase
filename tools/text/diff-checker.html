📊 Diff Checker

Compare two texts and see differences line by line. Green = added, Red = removed.

❓ FAQ

How does the diff algorithm work?
This tool uses a line-by-line diff algorithm that compares each line of the left text against the right text. Lines are marked as added (green), removed (red), or unchanged (white).
