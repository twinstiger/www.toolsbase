Frequently Asked Questions

What is Markdown Preview used for?+
Markdown Preview renders Markdown text in real-time as you type. Supports GitHub Flavored Markdown including tables, task lists, and code blocks.
Is my data sent to a server?+
No. All processing happens locally in your browser. Your data never leaves your device — zero server communication.
Is this free to use?+
Yes. Markdown Preview is completely free, no sign-up required, no rate limits, no ads. Just open and use.
