🔐 htpasswd Generator

Generate Apache/Nginx password hashes for .htpasswd authentication files. Supports bcrypt (recommended), MD5, SHA1, and crypt.

❓ FAQ

What algorithm should I use?
bcrypt is the recommended choice — it's the most secure and resistant to brute-force attacks. MD5 and SHA1 are legacy options supported for compatibility with older Apache installations.
How do I use this with Apache?
Add the generated line to your .htpasswd file (one entry per line). In your Apache config, set AuthUserFile /path/to/.htpasswd to protect a directory.
