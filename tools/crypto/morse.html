📡 Morse Code Encoder / Decoder

Convert text to Morse code and decode Morse back to text. Supports letters A-Z, numbers 0-9, and common punctuation.

—
Morse Code Reference
A = .-  B = -...  C = -.-.
0 = -----  1 = .----  2 = ..---
Space = /  Period = .-.-.-

❓ FAQ

What characters are supported?
Letters A-Z, numbers 0-9, and common punctuation (period, comma, question mark, exclamation, slash, parentheses, ampersand, colon, semicolon, equals, plus, minus, underscore, quotes, at).
Can I play the Morse code as sound?
Yes — click "Play Sound" to hear the Morse code. Each dot is a short beep, each dash is a longer beep.
