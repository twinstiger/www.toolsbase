❓ FAQ

What SQL dialects are supported?
This formatter works with standard ANSI SQL, including MySQL, PostgreSQL, SQLite, SQL Server, and Oracle SQL syntax.
Is my SQL data sent to a server?
No — all formatting is done locally in your browser using JavaScript. Your SQL never leaves your device.
