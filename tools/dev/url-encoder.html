❓ FAQ

What does URL encoding do?
URL encoding converts characters that aren't allowed in URLs (like spaces, &, #, or non-ASCII characters) into a safe format using % followed by two hex digits. For example, a space becomes %20.
When should I use URL encoding?
Use it when building URLs with query parameters that contain spaces or special characters, when passing text in URL paths, or when decoding query strings from server responses.
Is this tool safe?
Yes — all encoding and decoding happens locally in your browser. No data is sent to any server.
