Frequently Asked Questions

Unix timestamps can be in seconds (10 digits) or milliseconds (13 digits). JavaScript's Date.now() returns milliseconds. Python's time.time() returns seconds. This tool auto-detects which you're using — if the number is ≥ 1 trillion, it's treated as milliseconds.
The Unix epoch is January 1, 1970, 00:00:00 UTC. A Unix timestamp of 0 means exactly that moment. Every second after epoch increments the timestamp by 1 (in seconds) or 1000 (in milliseconds).
JavaScript: new Date(ts * 1000) (seconds). Python: datetime.fromtimestamp(ts). Node.js: same as Python. Bash: date -d @1609459200. Go: time.Unix(ts, 0).
