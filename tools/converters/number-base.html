❓ FAQ

What do the different bases mean?
Decimal (10) — standard counting system (0-9). Binary (2) — computer language (0-1). Octal (8) — compact 3-bit representation. Hexadecimal (16) — compact 4-bit representation used in colors and memory addresses.
How does auto-detection work?
If you prefix your number with 0x or 0X, it's treated as hex. 0b prefix means binary. 0 prefix (like 0777) means octal. Otherwise it's decimal.
