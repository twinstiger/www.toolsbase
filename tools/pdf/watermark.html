Frequently Asked Questions

Will the watermark be removable?+
No. The watermark is drawn directly into the page content stream, not added as an overlay. Once applied, it becomes part of the page like any other text. To remove it, the recipient would need to edit the raw PDF content.
Can I use a custom font?+
This tool uses pdf-lib's built-in standard fonts (Helvetica, Times, Courier) to keep things simple and dependency-free. For custom fonts, embedding a TTF file in the same tool would require file loading code we don't include by default.
What does "Tile" position do?+
Tile mode repeats the watermark across the entire page in a diagonal grid. Useful for marking draft documents where you want a clear visual signal on every part of the page.
Is my PDF safe?+
Yes. All processing happens in your browser using pdf-lib. Your file never leaves your device.
