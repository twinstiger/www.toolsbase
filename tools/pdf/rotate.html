Frequently Asked Questions

What's the difference between the three modes?+
All pages applies the same rotation to every page. Selected pages rotates only the pages you click on, by the global angle. Per-page rotation lets you set a different angle for each page using buttons under each thumbnail.
Does rotation affect page content or just orientation?+
pdf-lib applies rotation at the page level, which is a metadata change. The visual content is rendered rotated when viewed, with no quality loss. This is the same as how Adobe Reader rotates pages.
Can I rotate by arbitrary angles?+
PDFs only support 90°, 180°, and 270° rotations natively. For arbitrary angles, you'd need to convert pages to images first and rotate them — a more advanced operation not offered here.
Is my PDF safe?+
Yes. All processing happens in your browser using pdf-lib and pdfjs-dist. Your file never leaves your device.
