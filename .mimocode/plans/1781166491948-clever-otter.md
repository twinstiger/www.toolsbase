# 密码生成器页面修复计划

## 问题

1. HTML 结构错误：第 30 行 `</div>` 提前关闭 `.container`
2. FAQ 标题重复：前 3 个 FAQ 都叫 "What Makes a Password Strong?"
3. FAQ 缺少点击事件：前 3 个 FAQ 无法展开/收起
4. HTML 嵌套错误：FAQ 答案中有未关闭的 `<div>` 标签

## 修复

### 1. 修复 HTML 结构 (`tools/generators/password-generator.html`)
- 第 28 行：移除 `</div>`（这是 `.tool-page-header` 的关闭标签，但位置错误）
- 第 30 行：移除 `</div>`（这是 `.container` 的关闭标签，但应该在第 56 行之后）

正确结构：
```html
<div class="container">
  <div class="breadcrumbs">...</div>
  <div class="tool-page-header">
    <div class="tool-title-row">...</div>
    <p class="lead-text">...</p>
  </div>  <!-- 关闭 .tool-page-header -->
  
  <div class="tool-layout">...</div>
  <div class="tool-stats">...</div>
  <section class="faq-section">...</section>
</div>  <!-- 关闭 .container -->
```

### 2. 修复 FAQ 标题
将重复的标题改为有意义的描述：
- 第一个："Account Registration" → "Use Cases for Generated Passwords"
- 第二个："Password Manager Seeding" → "Password Manager Integration"  
- 第三个："WiFi and Network Credentials" → "Network Security"

### 3. 添加 FAQ 点击事件
在前 3 个 `.faq-item` 上添加 `onclick="toggleFaq(this)"`

### 4. 修复 HTML 嵌套
修复 FAQ 答案中的 `<div>` 标签：
```html
<!-- 修复前 -->
<div class="faq-answer"><p><strong>...</strong> — <div> — ...</p></div>

<!-- 修复后 -->
<div class="faq-answer"><p><strong>...</strong> — ...</p></div>
```

## 验证
- `npm run build` 构建成功
- 浏览器检查页面布局正常
- FAQ 可以点击展开/收起
